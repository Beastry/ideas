# Beastry Ideas

收集开源软件想法 · Collect open-source product ideas for Beastry.

这里不是产品仓库，而是社区共建的灵感板。欢迎用 Issue 提交想法；后续可能会加投票，现在先把点子说清楚。

This is not a product repo. Open an Issue to propose an idea. Voting may come later.

## 怎么提交 · How to submit

1. 点 [New issue](https://github.com/Beastry/ideas/issues/new/choose)，选 **Idea** 模板。
2. 写清：要解决什么问题、目标用户、你愿意怎么参与（讨论 / 设计 / 写代码）。
3. 保持友善、具体；重复想法请先搜已有 Issue 再评论。

English is welcome. Chinese is welcome. One idea per Issue.

## 状态标签（建议）

| 中文 | English | 含义 |
|------|---------|------|
| 构思 | Idea | 还在想，未立项 |
| 讨论中 | Discussing | 社区在聊细节 |
| 已立项 | Accepted | 准备或已开独立仓库 |
| 搁置 | On hold | 暂不推进 |
| 关闭 | Closed | 不做了或已合并到别的想法 |
